#  Maths Project 5 – Linear Algebra & Data Visualization Using Python

##  Project Overview

This project demonstrates the implementation of important Linear Algebra concepts using Python and a real-world student performance dataset in Google Colab / Jupyter Notebook.

The project uses libraries like NumPy, Pandas, and Matplotlib to perform vector operations, matrix calculations, eigenvalue decomposition, and graphical visualizations.

---

#  Objectives

* Understand basic Linear Algebra operations using Python.
* Perform vector and matrix calculations.
* Apply mathematical concepts on a real dataset.
* Visualize data in 2D and 3D graphs.
* Learn Eigenvalues and Eigenvectors.
